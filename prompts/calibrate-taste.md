# Prompt: calibrate taste from my own work

Paste this into a session where you can attach or point to images. Attach 5 to 8 screens you are proud of and 5 to 8 you would never ship (your own or anyone's). Say nothing about why; the point is to see whether Claude can read the difference.

---

Here are two sets of screens: set A is work I am proud of, set B is work I would never ship. Using typography-craft, product-ui-patterns and product-brand-identity as your vocabulary:

1. For every screen, write one line each for canvas, accent economy, type voice, hero figure, separation method, radius logic, imagery role, chrome, brand moment and signature, plus the measured values you can read off the screen (sizes, spacing, radii, line lengths, contrast where visible).

2. Tell me what separates set A from set B in rules, not adjectives. Each rule at class level, with values, always or never. Then tell me which rules the current skills already contain, which they contain too weakly, and which are missing.

3. Ask me why for the three differences you are least sure about. Do not guess my reasons.

4. Propose the missing and strengthened rules as diffs to kraftwrk-design-style (my taste) or to the relevant foundation skill (values, type, patterns, identity, review), each with the reason in my words. Wait for my approval before writing.

5. Write a references note for the repo (references/marcs-work.md): for each set A screen, one line on what it does right in the language of the ten decisions, so a future session can use it as a reference without the image.

Constraints: no em dashes; values follow Material Design 3 and Apple HIG unless the screen shows a deliberate exception, and then say what the exception is and why it works.
